# PackageControl
Sublime Text 的 Channel镜像 大陆用户可用的镜像

## 使用方式
菜单 - 首选项 - Package Settings - Package Control - Settings
```
	"channels": [
		"https://gh-proxy.com/https://github.com/svier0/PackageControl/releases/download/v1/channel_v4.json",
		"https://gh-proxy.com/https://github.com/svier0/PackageControl/releases/download/v1/channel_v3.json"
	],
```
